SECTION C | COMPLETION GUIDELINES

  1. Task Assigned / Undertaken: State each routine, management-assigned, or emergency task separately.
  2. Work Source: Identify the job description, supervisor, department head, management instruction, meeting, or email that originated the task.
  3. Work Done: Describe specific activities and measurable outputs achieved today.
  4. Completion (%): Give the actual estimated progress of each task (0–100%); use 100% only when fully completed.
  5. Remarks: State pending work, reasons for delay, dependencies, and next steps.
