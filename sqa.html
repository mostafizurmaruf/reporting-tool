HOW TO WRITE A MODULE

  1. One module per screen or feature area (Home Page, Attendance, Notification, Leave Management…). Each module becomes one chapter, like one tab in the Google Doc.
  2. Overview: 1–3 sentences on what the module is for and how the user gets there.
  3. Sections follow the screen from top to bottom: one section per card, banner, tab, form or list.
  4. Points: one point per line. Indent with Tab (or two spaces) for a sub-point, Shift+Tab to go back. Write Label: description and the label is shown in bold. Start a line with ### for a small sub-heading inside the section.
  5. Interaction: what happens on tap or click – where it navigates, which modal opens, what gets filtered.
  6. Table (optional) for color codes, status legends or field lists: one row per line, cells separated by |, first line is the header.
  7. Note permissions and rules too, e.g. “Only admins / HR can approve”. Fast start: ✨ Draft with Gemini turns rough notes or screenshots into a full module – review it before sharing.
